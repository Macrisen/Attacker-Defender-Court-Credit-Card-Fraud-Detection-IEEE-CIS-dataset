# Attacker-Defender-Court-Credit-Card-Fraud-Detection-IEEE-CIS-dataset-

Hybrid adversarial RL experiments on the IEEE-CIS dataset, with chronological
evaluation, frozen LightGBM baselines, delayed verification, and verified-only
Defender refits.

See [RUN_RESEARCH.md](RUN_RESEARCH.md) for training, resume commands, logs, and
checkpoint locations. The phase manifests under `reports/` record actual
execution status; a successful execution does not imply improved model performance.
